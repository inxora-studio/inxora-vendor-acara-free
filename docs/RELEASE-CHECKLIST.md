# Checklist rilis template bisnis

Starter ini belum merupakan template bisnis selesai.

- [ ] Brief kategori dan arah desain sudah terisi.
- [ ] Konten dan aset bersumber atau berlabel contoh.
- [ ] npm ci berjalan dari clone bersih.
- [ ] npm run check berhasil.
- [ ] npm run build berhasil.
- [ ] npm run build:static berhasil jika hosting statis dijanjikan.
- [ ] Seluruh interaksi diuji dengan mouse, sentuh, dan keyboard.
- [ ] Ponsel, tablet, desktop, fokus, dan kontras diperiksa.
- [ ] Loading, empty, dan error state sesuai kebutuhan fitur.
- [ ] Kontak, formulir, dan integrasi nyata setelah dikonfigurasi.
- [ ] URL, indexing, metadata, dan sitemap sesuai produksi.
- [ ] Free dan Premium masing-masing diuji sebagai paket mandiri.
- [ ] Source Premium tidak masuk dalam paket Free.
- [ ] Panduan, lisensi produk, dan cakupan bantuan tersedia.
- [ ] Secrets, artefak build, dan node_modules tidak ikut dikirim.
